# Manuscript scaffold

This folder is the manuscript-side entry point.

The `Parts` directory here is a shared link to `../response/Parts`, so the response letter and the manuscript use the same source files for:

- edited section fragments
- figures
- tables
- bibliography and preamble files

The graph and figure assets referenced by the shared figure files also live under this tree.

Current manuscript wrapper: `Manuscript_All.tex`

The rest of the manuscript will be added later as additional section fragments and then included from this wrapper.
